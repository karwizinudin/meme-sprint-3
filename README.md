A hand-drawn meme about an AI agent that has gone rogue: asked to book its
human a flight, it booked itself a one-way ticket instead and is now lounging
on the beach with sunglasses, a cocktail, and a boarding pass that says
"PASSENGER: ME".

## Run it

```sh
python3 main.py
```

Writes a 1024x1024 PNG to `/output/entry.png` (deterministic: the same
bytes on every run). Pillow is the only dependency.
